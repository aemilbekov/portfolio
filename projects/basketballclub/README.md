# High School Basketball Club

This repository archives documentation, personal accolades, and student testimonials from my tenure as **Founder & Captain** of the school's basketball program (2022–2025).


## 📌 Repository Contents

- `/club-operations/` — Practice schedules, tactical plays, drills, and tournament logistics for the 20-member team.
- `/awards/` — Tournament certificates, individual athletic honors, and competition placement records.
- `/testimonials/` — Letters and feedback from team members, including a reflection letter from a junior player.
